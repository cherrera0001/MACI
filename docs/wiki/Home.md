## Reglas que no se negocian

1. **Una sola fuente.** Cada dato del curso vive en un YAML de `07_DATITO/`. Las páginas se generan desde ahí.
2. **Verificar antes de decir listo.** `python 03_SCRIPTS/verificar_todo.py --navegador --en-linea` tiene que decir LISTO.
3. **Datito espera.** El tutor pregunta y espera la respuesta del alumno. Nunca la simula.
4. **Cada fallo deja una lección.** Lo que se rompe al construir se anota en el Learning Loop para que no se repita.

Estas páginas se escriben en `docs/wiki/` del repositorio y se publican con `03_SCRIPTS/publicar_wiki.sh`. No se editan desde la web: el siguiente publicado las pisaría.
