CAMBIOS PRINCIPALES APLICADOS
================================================================================

P1a (Curva ROC):
  + Tabla lecturas α → VP,FN,FP,VN para cada punto
  + Tabla cálculos TPR, FPR con coordenadas (FPR, TPR)
  + Canvas 2D dibujando ROC (sin Chart.js)
  + Explicación: qué es TPR/FPR, por qué (0,0) y (1,1) son malos
  + Errores específicos: confundir VP con TPR, invertir ejes, olvidar normalización
  + Checklist: 8 items para verificar respuesta en examen

P1b-P1d (Comparación, umbral, escalamiento):
  + Ampliadas con tablas, contextualización clínica
  + Pasos explícitos de razonamiento
  + Errores y checklists específicos

P2a (Overfitting):
  + Tabla RMSE entrenamiento vs prueba para todos los grados
  + Cálculo del gap (brecha = 73 para grado 10)
  + Explicación de por qué brecha = síntoma de overfitting
  + Diferencia conceptual: RMSE bajo en entrenamiento ≠ buen modelo

P2b (Modelo óptimo):
  + Gráfico RMSE_prueba por grado (grado 3 es mínimo)
  + Explicación bias-variance trade-off
  + Por qué grado 5+ empieza a crecer nuevamente

P2c (Métricas):
  + Interpretación de Media (sesgo = +3 kWh subestima)
  + Interpretación de Desv.Std (variabilidad = ±30 kWh)
  + Interpretación de RMSE (error típico = 30 kWh)
  + Relación: RMSE² ≈ media² + desv.std²
  + Contexto: "Si consumo real = 100 kWh, error esperado ±30"

P3a (IA adopción):
  + Gráfico McKinsey (descripto): 20% → 88%
  + Explicación de brecha: 88% usan IA, solo 7% completamente integrada
  + Razones organizacionales: cambio cultural, inversión, gobernanza

P3b (Calibración sensores):
  + Histograma bimodal: Proveedor 1 (60°C) vs Proveedor 2 (140°C)
  + Hipótesis: Offset de calibración (~80°C)
  + Método de verificación: separar por proveedor
  + Corrección: estandarización (restar media por proveedor)

P3c (LLM limitaciones):
  + Limitación 1: Alucinaciones (inventa información)
  + Limitación 2: No accede a datos reales (sin API a sensores, BD)
  + Solución: Agente basado en LLM (LLM + herramientas externas)
  + Funcionamiento: LLM razona, herramientas ejecutan

P3d (Agentes secuencia):
  + 5 pasos explícitos: lectura sensor → razonamiento → consulta manual → decisión → ejecución
  + Datos reales: T=165°C (anomalía detectada)
  + Roles: LLM (razonador), Entorno (datos), Herramientas (APIs)
  + Por qué Agente > LLM: acceso a datos + ejecución de acciones + retroalimentación
